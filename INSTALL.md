# Installation — Nithish S GitHub profile

1. Open your special GitHub profile repository: **Nithish23013509/Nithish23013509**. If it doesn't exist, create a **public** repository with that exact name.
2. Upload `README.md` at the repository **root** and upload the entire `assets` folder beside it.
3. Commit your changes and visit [github.com/Nithish23013509](https://github.com/Nithish23013509).
4. If you edit visual labels, modify the self-contained SVG files in `assets/`. The images use no external fonts, scripts, APIs, or CSS.

**Important:** GitHub does not run ordinary custom JavaScript in README files. This design achieves motion using embedded SVG animation and native README interactions (`<details>`). GitHub's renderer, user/browser motion preferences, and image caching may affect animation playback. All banners are designed to remain readable as static images.

**Mobile:** The header and toolkit have mobile SVG variants referenced using `<picture>`; if GitHub doesn't honor mobile `<source>` on a specific client, the desktop image is a usable fallback.

**External stats:** the telemetry sources are the third-party URLs from your existing profile. They may sometimes be unavailable or cache older data. They are deliberately in a collapsible section to keep the top of the profile clean.

The PNG in `previews` is a static visual preview, not required for GitHub.
